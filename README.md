# GD32 × LVGL Resources

This repository provides a centralized overview of the official **GigaDevice GD32 MCU LVGL example projects**.

The projects are maintained by the [GigaDevice-GD32-MCU](https://github.com/GigaDevice-GD32-MCU) organization and cover different GD32 MCU families and evaluation boards. They provide practical references for integrating **LVGL with GD32 MCUs**, including display interfaces such as SPI, EXMC, RGB, and TLI.

The table below summarizes the currently identified official LVGL repositories and provides direct links to the corresponding GitHub projects.

## Official LVGL Projects

| MCU Series | Evaluation Board | LVGL | Resolution | Pixel Format | Interface | Repository |
|---|---|---|---|---|---|---|
| GD32C231 | GD32C231C-EVAL | V8.3.11 | 240×320 | RGB565 | SPI | [GD32C231_EVAL_LVGL](https://github.com/GigaDevice-GD32-MCU/GD32C231_EVAL_LVGL) |
| GD32F503 | GD32F503V-EVAL | V8.3.11 | 240×320 | RGB565 | 8080 / EXMC | [GD32F503_EVAL_LVGL](https://github.com/GigaDevice-GD32-MCU/GD32F503_EVAL_LVGL) |
| GD32F527 | GD32F527I-EVAL | V8.3.11 | 480×272 | RGB565 | RGB | [GD32F527_EVAL_LVGL](https://github.com/GigaDevice-GD32-MCU/GD32F527_EVAL_LVGL) |
| GD32F5HC | GD32F5HC-EVAL | V8.3.11 | 240×320 | RGB565 | SPI | [GD32F5HC_EVAL_LVGL](https://github.com/GigaDevice-GD32-MCU/GD32F5HC_EVAL_LVGL) |
| GD32H759 | GD32H759I-EVAL | V8.3.11 | 480×272 | RGB565 | RGB / TLI | [GD32H759_EVAL_LVGL](https://github.com/GigaDevice-GD32-MCU/GD32H759_EVAL_LVGL) |
| GD32W515 | GD32W515-EVAL | V8.3.11 | 320×240 | RGB565 | SPI | [GD32W515_EVAL_LVGL](https://github.com/GigaDevice-GD32-MCU/GD32W515_EVAL_LVGL) |

These projects are provided as reference implementations for GD32-based embedded GUI applications using LVGL. For the latest information about each MCU, evaluation board, display configuration, and software environment, please refer to the corresponding official repository.

For more GD32 software resources, please visit the official [GigaDevice-GD32-MCU](https://github.com/GigaDevice-GD32-MCU) GitHub organization.

# GD32 × LVGL 资源汇总

本仓库用于集中整理 **GigaDevice GD32 MCU 官方 LVGL 示例工程**。

这些项目由 [GigaDevice-GD32-MCU](https://github.com/GigaDevice-GD32-MCU) 官方 GitHub 组织维护，覆盖不同 GD32 MCU 系列及评估板，可作为 **GD32 MCU 集成 LVGL 图形库**的参考工程，涉及 SPI、EXMC、RGB、TLI 等不同显示接口方案。

下表汇总了目前整理到的官方 LVGL 相关仓库，并将 **分辨率、像素格式、接口** 分别列出，同时提供对应 GitHub 项目的直接跳转链接。

更多 GD32 软件资源，请访问 [GigaDevice-GD32-MCU](https://github.com/GigaDevice-GD32-MCU) 官方 GitHub 组织。
